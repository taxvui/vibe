# Dependency security maintenance

This update is based on the Yarn Classic lockfile on `master`, audited on 2026-10-18. The initial npm audit contained **182 distinct advisories**: 6 critical, 99 high, 68 moderate, and 9 low. Dependency paths are deduplicated by advisory URL; these numbers are not GitHub's Dependabot alert count.

The updated lockfile has **2 distinct advisories** (0 critical, 1 high, 1 moderate, 0 low). There are 26 affected dependency paths; these are not 26 different vulnerabilities. The verified GitHub run built all 64 core projects, verified declaration entry points, passed 44 Button tests, and built the production Storybook.

## Changes

- Refresh affected dependencies within their declared version ranges, using registry metadata and integrity hashes generated by Yarn.
- Upgrade Lerna 8 to Lerna 10 to replace the vulnerable legacy build dependency tree, including tar, Nx, and npm tooling.
- Pin the development default to Node 24.19.0 in `.nvmrc`. The root engine constraint follows Lerna's supported Node release lines; published React peer ranges are unchanged.
- Replace deprecated `rollup-plugin-terser` with the official `@rollup/plugin-terser` in all four build configurations. The replacement supports the existing Rollup 2/3 versions and uses patched `serialize-javascript`.
- Upgrade the directly pinned PostCSS 8 dependency. Use scoped resolutions for the patched Nx/Undici and external-editor/tmp dependencies.
- Pin the real `@types/parse-path` definitions to 7.0.3 to avoid the empty stub package entering TypeScript's implicit type libraries.
- Make the TypeScript Rollup include patterns explicit. This avoids legacy empty-alternative extglobs in the default filter after updating glob dependencies. CI checks that public declaration entry points are emitted.

## Reproduce

```sh
nvm install
corepack enable
corepack prepare yarn@1.22.22 --activate
yarn install --frozen-lockfile --ignore-scripts
yarn audit --json > security-audit.jsonl
# Yarn's nonzero audit exit code reports findings. Inspect the complete output:
node scripts/check-security-audit.cjs security-audit.jsonl
node --test scripts/check-security-audit.test.cjs
SKIP_RELEASE_ARTIFACTS=true yarn build:package @vibe/core
yarn workspace @vibe/button test
yarn workspace vibe-storybook-components build
NODE_OPTIONS=--max-old-space-size=6144 yarn workspace @vibe/docs build-storybook
```

The dependency-security workflow runs without publishing credentials. It preserves the complete audit output as an artifact. Its gate fails on an incomplete audit or unexpected high/critical findings; a green gate does **not** mean there are no advisories.

## Remaining work

- **braces / GHSA-vfj7-8cjw-p6xm (high):** upstream currently lists no patched release. It remains visible in audit output. The CI exception applies only to this exact advisory while its patched range is empty; a newly available patch fails the gate and requires an update. Do not pass untrusted patterns to the lint/build glob tooling. [Advisory](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm).
- **postcss-selector-parser / GHSA-rj75-hqrm-r3gf (moderate):** Stylelint 14 uses parser 6. Fixing this requires a coordinated Stylelint/config migration to a parser release at least 7.1.6. This update retains the existing Stylelint API and rules instead of forcing an undeclared major parser version. [Advisory](https://github.com/advisories/GHSA-rj75-hqrm-r3gf).
