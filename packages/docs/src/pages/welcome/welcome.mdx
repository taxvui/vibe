## Clarity before decoration

Use solid surfaces for dense content. Introduce glass where separation and context help people understand an interface. The quietest useful material is the best default.

## Built on working foundations

Prism extends Vibe's existing React components and accessibility primitives. Buttons, forms, tabs and overlays keep their established APIs. Theme variables coordinate color, typography, spacing, motion and materials.

## Choose your path

The live showcase demonstrates the new material system. The Catalog, Foundations and component reference retain upstream documentation for existing APIs. Prism additions are available in this fork's workspace source; they are not included in the public npm release.
